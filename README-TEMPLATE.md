# Template de Landing

Use esta pasta como base para novas landings mantendo o mesmo visual.

O que normalmente trocar:

1. `index.html`
- título da página
- nome da marca
- textos das seções
- CTAs e links
- listas e comparativos
- WhatsApp e e-mail

2. `assets/`
- favicon
- screenshots
- imagens do produto

3. manter igual
- `styles.css`
- `script.js`
- `Dockerfile`
- `nginx.conf`

Fluxo simples:

1. Duplicar esta pasta
2. Renomear para o novo projeto
3. Trocar conteúdo do `index.html`
4. Substituir imagens em `assets/`
5. Testar
6. Subir no Git/Coolify
