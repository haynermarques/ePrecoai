# PreçoAI — Ecossistema para o comércio

Site institucional estático (nginx) com as três soluções do ecossistema:

- `index.html` — home, com os 3 cartões que levam às páginas internas
- `catalogo.html` — Catálogo e comércio digital
- `atendimento.html` — Atendimento com CRM e IA
- `precos.html` — Gestão de ofertas, inteligência de preços e gerador de posts
- `duvidas.html` — Perguntas frequentes

Estilos: `styles.css` (base) + `ecossistema.css` (componentes novos). Todo CTA "Fale conosco" abre o WhatsApp.
Vídeos marcados como "Placeholder" nas páginas internas devem ser substituídos pelas gravações reais.
